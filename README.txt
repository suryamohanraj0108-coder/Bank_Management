Project Title: Bank Management System

Description:
This is a console-based C++ application developed to manage bank account records using object-oriented programming and file handling.

Features:
-Create new bank account
-Deposit amount
-Withdraw amount
-Balance inquiry
-Display all account details
-Persistent file storage using binary files

How to Run:
1. Compile: g++ main.cpp -o bank
2. Run: bank

Files:
-main.cpp → Source code
-bank.dat → Account data storage

Concepts Used:
-Classes and Objects
-Encapsulation
-File Handling
-Functions
-Conditional Statements
